# 界面范围与验收方向

## 当前：v3.2.0 照片优先与轻快操作

模式：Operate。用户明确要求解决图片慢、操作卡顿和视觉不美观，已确认首页突出「诱人的食物照片＋快速决定」。本轮替换旧版视觉布局，保持真实功能和数据契约。方向为现代鲜食菜单，种子 e3728965。

首屏路径为看推荐大图、直接选择或换一道；转盘作为辅助方式保留。桌面侧栏与大图/转盘两栏，手机推荐在前、五项底部导航；菜单、计划、收藏、记录和设置共用明暗/六色系统。照片来自既有项目，参考图与原图保持区分，不新增营养、门店经营等无法证实的说法。

性能由分尺寸 WebP、原生图片加载、静态占位、合成层转盘及局部更新支撑。采用两轮主体视觉检查，之后只修复复核列出的 320px 主动作问题。最终依据为 v320-final-* 与 v320-verdict-* 截图、72 项完整浏览器回归及新增窄屏检查；详见 visual-review-v3.2.md 和 performance-v3.2.json。

独立复核代理两次返回环境 403，采用主会话备用复核，不宣称独立审查。

## 历史：v3.0 / v3.1

模式：Operate。此轮是已有美食决策工具的整体重构和界面优化，保留现有暖色身份、碗形标记、本地菜品图和六种配色；没有替换视觉世界、生成对比稿或独立品牌设计要求。

用户确认新增方向：用餐计划、饮食偏好、完整备份。首要操作是快速决定一餐；桌面并列转盘和推荐，手机把抽取置于首屏并提供底部导航。分类按需展开，复杂设置单独呈现。

现有功能必须保留：转盘、分类/餐次、搜索、收藏、历史、淘汰赛、音效、摇一摇、分享图片、附近店铺与外卖入口、自定义菜单与替换模式、PWA。新计划支持空位生成、手动替换、锁定、已吃打卡与复制；偏好贯穿自动选择。

图像使用已有真实资产，加载时显示本地名称卡。界面不宣称实际外卖平台收录、菜品配料保证、热量或营养数据。未知店铺不通过严格饮食标签筛选。

原重构的视觉证据位于 `.playwright-mcp/round1-*` 和 `final-*`，原重构检测为零发现。

2026-10-28 追加：用户要求转盘和全站界面更好看、更精致。延续既有暖色身份，收敛转盘为奶油色几何扇区、细线外圈与陶土色中心，最多显示 8 项正向实物照片；指针、照片和结果一致。导航、图片留边、卡片、按钮、设置开关和手机布局同步精修，保留全部业务行为。

本轮采用一次合并截图检查、一次集中修复与一次最终确认。初检截图为 `.playwright-mcp/ui-round1-*`；版本 3.1.0 的最终截图为 `ui-final-*`。本轮单次设计检测报告 DESIGN.md 缺少完整字号/圆角/颜色记录的 advisory，最终按实际样式同步设计记录，不将该结果记为零发现。
