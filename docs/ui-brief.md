# 界面范围与验收方向

模式：Operate。此轮是已有美食决策工具的整体重构和界面优化，保留现有暖色身份、碗形标记、本地菜品图和六种配色；没有替换视觉世界、生成对比稿或独立品牌设计要求。

用户确认新增方向：用餐计划、饮食偏好、完整备份。首要操作是快速决定一餐；桌面并列转盘和推荐，手机把抽取置于首屏并提供底部导航。分类按需展开，复杂设置单独呈现。

现有功能必须保留：转盘、分类/餐次、搜索、收藏、历史、淘汰赛、音效、摇一摇、分享图片、附近店铺与外卖入口、自定义菜单与替换模式、PWA。新计划支持空位生成、手动替换、锁定、已吃打卡与复制；偏好贯穿自动选择。

图像使用已有真实资产，加载时显示本地名称卡。界面不宣称实际外卖平台收录、菜品配料保证、热量或营养数据。未知店铺不通过严格饮食标签筛选。

原重构的视觉证据位于 `.playwright-mcp/round1-*` 和 `final-*`，原重构检测为零发现。

2026-10-28 追加：用户要求转盘和全站界面更好看、更精致。延续既有暖色身份，收敛转盘为奶油色几何扇区、细线外圈与陶土色中心，最多显示 8 项正向实物照片；指针、照片和结果一致。导航、图片留边、卡片、按钮、设置开关和手机布局同步精修，保留全部业务行为。
