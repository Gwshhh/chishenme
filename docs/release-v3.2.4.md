# v3.2.4 天气、手机访问与加载优化

主站：<https://eat.zhouquanji.eu.cc/>。原地址 <https://gwshhh.github.io/chishenme/> 继续保留；本地数据按浏览器来源隔离，切换域名前可在设置中导出完整备份，再到新站导入。没有自动重定向或清除原站数据。

## 改动

- 附近区域使用苹果天气风格的地区卡片，显示城市、区县、温度、天气和真实每日高低温。昼夜由数据决定；无数据保留占位，刷新失败的旧值明确标为「上次天气」。
- iPhone 的原报错发生在连接 workers.dev 时，早于 GPS。新增自有域名入口；用户已用原来的 iPhone 网络打开新 API 并确认 nearby / weather 均为 true。
- 手机美团入口在点击内直接唤起 App，搜索词正确编码，不等待剪贴板。未打开时保留可见的网页版入口，内嵌浏览器给出系统浏览器提示。高德店铺编号不会当成美团编号。
- 29 个模块合并为单个应用包，启动只请求该包与小型主题脚本；离线壳由 38 项减少到 12 项。安装离线壳不再等待远端店铺能力检查。
- 原生 picture 在手机选择 480/768px 图片，桌面保留 480/960px。768px 图每张小于 90 kB。转盘参考缩略图不抢先下载整张店铺原图，远程图最多 3 个并发并优先主图。

![天气地区卡片，演示数据](weather-v3.2.4.webp)

## 受控性能比较

三个全新 iPhone 尺寸 Chromium 上下文的中位数；本地 gzip 服务、150ms RTT、1.6Mbps 下载、4 倍 CPU 降速。旧版本为 e25651ad，非真实运营商测速或全设备承诺。

| 指标 | v3.2.3 | v3.2.4 |
| --- | ---: | ---: |
| 页面可操作 | 1.85 秒 | 0.99 秒 |
| 首屏主图加载完成 | 4.16 秒 | 2.44 秒 |
| 启动脚本请求 | 28 | 2 |
| 脚本传输量（含请求开销） | 71,224 bytes | 42,202 bytes |
| 本次测试主图文件 | 239,660 bytes | 79,656 bytes |

原始记录：[performance-v3.2.4.json](performance-v3.2.4.json)。使用 `node scripts/benchmark-startup.mjs` 复现，需要本地保留基线提交。记录中的早期 LCP 候选不作为最终 LCP 结论；基准后仅增加了旧天气提示，不改变初始加载路径。
